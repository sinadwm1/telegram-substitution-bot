# ربات تبدیل نویسهٔ تلگرام

[English guide](README.md)

ربات کوچکی که حروف لاتین متن را طبق جدول ثابت به نویسه‌های دیگر تبدیل و نتیجه را ارسال می‌کند. این کار **رمزنگاری امن نیست** و فقط یک تمرین تبدیل متن است.

۱. توکن موجود در نسخهٔ محلی اولیه را در BotFather باطل و توکن تازه بسازید.
۲. متغیر محیطی `BOT_TOKEN` را تنظیم کنید. فایل `.env.example` به‌صورت خودکار خوانده نمی‌شود.
۳. اجرا کنید:

```bash
pip install -r requirements.txt
python bot.py
```

نسخهٔ آماده‌شده هنوز با API زندهٔ تلگرام آزمایش نشده و این نسخه با مجوز MIT منتشر می‌شود.
